# 오늘의 스크랩

경제구조개혁국 관련 **일일 기사 스크랩**을 도와주는 웹 앱입니다.
시작·끝 시간을 정하면 언론사 RSS에서 그 시간대의 기사를 모아 **7개 키워드(노동·교육·청년·인구·연금·AI·양극화)별로 4~5건씩 추천**하고,
고른 기사를 **텍스트 파일 · 한눈에 보기 이미지 · 보고서(PDF/워드)** 로 한 번에 내려받을 수 있습니다.

> 개인이 만든 업무 보조 도구이며, 특정 기관의 공식 서비스가 아닙니다.
> 요약·점수·추천 결과는 참고용이므로 반드시 원문을 확인해 주세요. 기사의 저작권은 각 언론사에 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 기간 지정 검색 | 시작·끝 시간(최대 48시간, 한국시간 기준)을 정해 기사를 모음. "최근 24시간" 같은 빠른 선택 버튼 제공 |
| 키워드별 추천 | 같은 내용의 기사를 하나로 묶고, 업무 관련성·키워드 적합도·언급량·정책/시한 낱말을 합산한 **100점 만점 총점**으로 순위를 매김 (항목별 점수 표시) |
| 대표 기사 선정 | 같은 내용을 여러 보도사가 썼을 때 규모가 큰 보도사(지면 발행 기준)의 기사를 대표로 보여 줌. 본문을 가져올 수 없는 기사는 선정하지 않음 |
| 놓친 이슈 레이더 | 7개 키워드 밖이지만 여러 보도사가 크게 다룬 이슈(경제·정책 / 정치·사건)를 따로 보여 줌 |
| 본문 보기 | 기사 본문을 가져와 보여 주고, 발언 모음·용어 풀이를 함께 표시 |
| 선택·순서 정하기 | 기사를 체크하고 ↑↓로 순서를 바꿈 |
| 텍스트 파일 | 맨 앞 "한눈에 보기" 요약 목록 + 기사 전문을 담은 `.txt` |
| 한눈에 보기 이미지 | 선택한 기사를 A4 1~2장에 요약 카드로 모은 `.png` |
| 보고서 | 표지 + 기사별 전문(기사마다 새 쪽)을 보여 주고 **PDF로 저장** 또는 **워드(.doc)로 받기** |

## 동작 방식

1. **수집** — 허용된 언론사 RSS(약 120개 주소)에서 시간 범위 안의 기사만 모음
2. **중복 제거** — 제목 유사도로 같은 내용을 묶고 언급량(다룬 보도사 수)을 계산
3. **점수·선별** — 업무 관련성 40 · 키워드 적합도 25 · 언급량 25 · 정책/시한 10, 사설·칼럼은 −20
4. **본문** — 추천된 기사 링크를 한 건씩 읽어 본문 글자만 정제해 가져옴
5. **내보내기** — 텍스트 / 이미지 / 보고서

AI 모델을 쓰지 않는 **규칙 기반** 도구이며, 외부 API 키가 필요 없습니다.

## 개인정보·보안

- 검색 결과와 본문을 **서버에 저장하지 않고**, 캐시하지 않으며, 기사 내용을 로그에 남기지 않습니다.
- 로그인·개인정보 수집 기능이 없습니다.
- 본문을 가져올 때는 허용된 언론사 도메인만 접속하고, 내부 주소 차단 · 이동 횟수·시간·크기 제한을 적용합니다. (SSRF 방어)
- 다른 사이트가 몰래 보낸 요청은 `Origin` 검사로 막습니다.

## 기술 스택

- [Next.js](https://nextjs.org) 16 (App Router) · TypeScript · Tailwind CSS v4
- RSS 읽기: `fast-xml-parser` / 본문 추출: `@mozilla/readability` + `jsdom`
- 배포: Vercel

## 직접 실행하기

```bash
npm install
npm run dev     # http://localhost:3000
```

```bash
npm run build   # 배포용 빌드
npm run lint    # 코드 검사
```

필요한 환경 변수는 없습니다.

## 폴더 구조

```
app/        화면(페이지)과 API (/api/search, /api/article, /api/export)
lib/        기사 수집·묶기·점수·선별·본문 추출·문서 만들기 로직과 설정(config.ts, feeds.ts)
public/     정적 파일
PRD.md      서비스 기획서
PLAN.md     개발 계획
DESIGN.md   설계 문서
CHECK.md    점검 기록
```

## 설정 바꾸기

- 키워드·낱말·점수 비중·기준값: `lib/config.ts`
- 수집할 언론사 RSS: `lib/feeds.ts`
- 보도사 대표 선정 순서: `lib/config.ts`의 `SOURCE_TIERS`
- 용어 풀이: `lib/glossary.ts` (초안이므로 검수가 필요합니다)

## 알려진 한계

- 일부 언론사(조선일보·MBN 등)는 본문을 가져올 수 없어 기사로 선정하지 않습니다.
- RSS는 최근 기사만 제공하므로 오래된 기간의 타임라인은 만들 수 없습니다.
- 요약은 본문 앞부분 문장을 규칙으로 고른 것이라 어색할 수 있습니다.
- 사진은 포함하지 않습니다. (워드 파일에서 직접 첨부)
